# Security Policy

## Supported versions

Security fixes are intended for the latest version on the default branch and
the latest published release.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues or pull requests. Use
[GitHub's private vulnerability reporting](https://github.com/cody3629/Bionic-Reader-VSCode-Extension/security/advisories/new) to
send the maintainer a description, reproduction steps, affected versions, and
any suggested mitigation.

If private reporting is unavailable, do not disclose the vulnerability
publicly. The maintainer must enable private vulnerability reporting before
this channel can receive reports.
